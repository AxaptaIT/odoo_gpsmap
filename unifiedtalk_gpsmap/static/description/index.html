The live fleet map, inside Odoo

People sign in to Odoo first. GPS Map then opens already signed in. There is no second login page.

1

Install

An administrator installs GPS Map from the Apps menu. A person who is not logged into Odoo does not see it.

2

Activate

The administrator enters one activation key. The key loads the connection. No gateway or company id is typed in.

3

Open the map

GPS Map appears in the app switcher, next to Sales and Contacts. Opening it launches the live map.

Who can open the map

Enterprise

The administrator adds the person to the GPS Map group. Everyone in that group opens the map as the one user stored on the activation key.

Limited

The activation key includes a list of user names. The administrator assigns each name to one Odoo user from Assigned users.
