GPS Map

Open the live fleet map from Odoo. The user signs in to Odoo first. GPS Map then opens already signed in.

After installation, an administrator enters the activation key supplied for the company. The key loads the connection. The administrator does not type a gateway, company, or application id.

Who can open the map

  • Open. An administrator adds the Odoo user to the GPS Map group. Everyone granted that group opens the map as the one user stored on the activation key.
  • Permitted. The activation key includes a list of user names. An administrator assigns each name to one Odoo user.

A person who is not logged into Odoo does not see the GPS Map menu.
